## 一、先说清这次“Driver not loaded / database not open”的真正原因

这两个报错很容易被误认为“SQLite 驱动没装”，实际排查结果是**代码顺序问题 + 连接名不一致**，驱动本身完全正常：

1. `D:\software\Qt\Qt5.12.11\5.12.11\mingw73_64\plugins\sqldrivers\qsqlite.dll` 确实存在，驱动没问题。
2. `main.cpp` 里原来写的是：

   ```cpp
   MainWindow w;
   w.show();
   DBHelper::getInstance()->closeDatabase();   // ← 错在这里
   return a.exec();                            // 事件循环还没开始，连接就被关了
   ```

   窗口一显示连接就被关闭，之后登录按钮再去 `prepare()` 就会报 `database not open`。

3. 另一处隐患：`DBHelper` 原来用的是**命名连接**（比如 `hospital_conn`），而医生页的 `QSqlQueryModel` 不带连接参数，只能用 Qt 的**默认连接**，于是 `setQuery` 失败，弹出模态 `QMessageBox`，在无人值守的自检里表现为“程序卡住不退出”。

最终统一改成：

- `DBHelper` 使用 **Qt 默认连接**（`QSqlDatabase::addDatabase("QSQLITE")`）；
- 所有 `QSqlQuery` 显式绑定 `m_db`；
- `closeDatabase()` 移到 `a.exec()` **之后**；
- `QSqlQueryModel` 不带参数构造，自动用默认连接。

改完后 `--selftest` 14 项全部通过，界面截图也正常。

## 二、整体设计

四个层次，职责清晰：

| 层次 | 具体类 | 职责 |
| --- | --- | --- |
| 数据访问层 | `DBHelper`（单例） | 打开数据库、建表、默认数据、全部 SQL 封装、错误信息回传 |
| 模型层 | `PatientTableModel`（继承 QSqlTableModel）、`QSqlTableModel`（科室）、`QSqlQueryModel`（医生） | 把表数据暴露给视图 |
| 代理层 | `PatientDelegate`（继承 QStyledItemDelegate） | 性别用下拉框、出生日期用日历，其余列禁止乱改 |
| 视图层 | `MainWindow` + `QStackedWidget` + 各页面控件 | 登录、主页、三个管理页、两个对话框 |

页面切换用 `QStackedWidget`：5 个页面（登录 / 主页 / 患者 / 科室 / 医生）常驻内存，切换时只改索引，不销毁重建，所以数据不会丢。

数据流（以“新增患者”为例）：

```
按钮点击 → EditPatientDialog 收集并校验输入
        → DBHelper::insertPatient()（拼 SQL、执行、把失败原因写进 message）
        → 成功则写 History 日志 + refreshTable() 刷新 QSqlTableModel
        → 失败则 QMessageBox 显示具体原因（主键重复 / 身份证重复 / 字段非法）
```

### 3. dbhelper.cpp —— 打开数据库、建表

```cpp
bool DBHelper::initDatabase()
{
    // 用 Qt 默认连接：QSqlQueryModel 不带连接参数时也能直接用
    const QString connName = QLatin1String(QSqlDatabase::defaultConnection);
    if (QSqlDatabase::contains(connName))
        m_db = QSqlDatabase::database(connName);
    else
        m_db = QSqlDatabase::addDatabase("QSQLITE");   // SQLite 驱动

    // 数据库文件放在 exe 同目录，避免“Creator 运行”和“双击运行”打开两个库
    m_db.setDatabaseName(QCoreApplication::applicationDirPath() + "/hospital.db");

    if (!m_db.isOpen() && !m_db.open()) {
        qCritical() << "数据库打开失败：" << m_db.lastError().text();
        return false;                    // 返回 false，由 main 弹窗提示
    }

    QSqlQuery pragma(m_db);
    pragma.exec("PRAGMA foreign_keys = ON");   // SQLite 默认不校验外键，要手动打开

    return createTables() && initDefaultData();
}
```

`execSql()` 是所有 SQL 的总入口，统一做三件事：准备语句、绑定参数、把错误文本写进 `message`：

```cpp
bool DBHelper::execSql(const QString &sql, const QVariantList &params, QString *message)
{
    if (message) message->clear();
    if (!m_db.isOpen()) {            // 连接没开就直接给出原因，避免“莫名失败”
        if (message) *message = "数据库未连接";
        return false;
    }
    QSqlQuery q(m_db);
    if (!q.prepare(sql)) { if (message) *message = q.lastError().text(); return false; }
    for (int i = 0; i < params.size(); ++i)
        q.addBindValue(params.at(i));
    if (!q.exec()) { if (message) *message = q.lastError().text(); return false; }
    return true;
}
```

### 8. patienttablemodel.h —— 自定义 Model（性别显示）

```cpp
class PatientTableModel : public QSqlTableModel
{
public:
    QVariant data(const QModelIndex &index, int role = Qt::DisplayRole) const override
    {
        // 第 3 列是“性别”，数据库存 0/1，这里只改显示文本
        if (role == Qt::DisplayRole && index.column() == 3) {
            return QSqlTableModel::data(index, role).toInt() == 1 ? "女" : "男";
        }
        return QSqlTableModel::data(index, role);   // 其它列/角色交给父类
    }
};
```

注意两点：
- 只改 `DisplayRole`，`EditRole` 仍是 0/1，代理里的下拉框可以用 `currentIndex()` 直接定位；
- 列号必须按实际顺序数（编号 0、身份证 1、姓名 2、**性别 3**、出生日期 4……），一开始写成 6 就把“体重”列显示成了男/女。

### 9. patientdelegate.cpp —— 自定义代理

```cpp
QWidget *PatientDelegate::createEditor(QWidget *parent, ...) const
{
    if (index.column() == ColSex) {                    // 性别 → 下拉框
        QComboBox *box = new QComboBox(parent);
        box->addItem("男"); box->addItem("女");
        return box;
    }
    if (index.column() == ColDob) {                    // 出生日期 → 日历
        QDateEdit *edit = new QDateEdit(parent);
        edit->setCalendarPopup(true);
        edit->setDisplayFormat("yyyy-MM-dd");
        edit->setMaximumDate(QDate::currentDate());
        return edit;
    }
    return nullptr;                                    // 其它列不允许直接在表格里改
}

void PatientDelegate::setModelData(QWidget *editor, QAbstractItemModel *model,
                                   const QModelIndex &index) const
{
    if (index.column() == ColSex)
        model->setData(index, qobject_cast<QComboBox*>(editor)->currentIndex(), Qt::EditRole);
    else if (index.column() == ColDob) {
        const QDate d = qobject_cast<QDateEdit*>(editor)->date();
        model->setData(index, d.toString("yyyy-MM-dd"), Qt::EditRole);
        model->setData(index, ageFromDate(d), Qt::EditRole);   // 同步更新年龄列
    }
}

void PatientDelegate::updateEditorGeometry(QWidget *editor, const QStyleOptionViewItem &option,
                                           const QModelIndex &) const
{
    editor->setGeometry(option.rect);   // 编辑器覆盖整个单元格，位置不跑偏
}
```

## 五、几个必须知道的“坑”

1. **QSS 的 `min-height` 会覆盖 `setFixedSize()` 的最小尺寸**。主页三个按钮写的是 170×140，但 `QPushButton { min-height: 22px }` 生效后高度被压成 24px。解决办法：在 `QPushButton#HomeButton` 里显式写 `min-width/max-width/min-height/max-height`。
2. **`QSqlQueryModel` 没有带 `QSqlDatabase` 参数的构造函数**（Qt 5.12 没有），所以统一依赖默认连接。
3. **`QAbstractItemView::commitData` 是 protected**，不能 `connect(&QTableView::commitData, ...)`，要用代理的 `closeEditor` 信号。
4. **QSS 用 C++ 原始字符串（raw string）时结尾必须是 `)QSS";`**，少一个字符就报 `unterminated raw string`。
5. **删除 `hospital.db` 可以重置数据**：库文件在 exe 同目录（`...\debug\hospital.db`），改表结构后先删掉它再运行。
6. **不要用中文标点写代码**：`；`、`（）`、`，` 都会报“类型未定义/语法错误”。
